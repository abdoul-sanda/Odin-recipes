### Odin Recipes

Mais ils sont pas difficiles à faire chez soi et pas difficiles à se procurer non plus

### Pour chaque plat

Pour chacun de ses plats j'ai mis
- une petite description du plat 
- les ingrédients 
- le processus de préparation de celui-ci
